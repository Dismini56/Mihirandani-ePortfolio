# Mihirandani – Personal Portfolio

## About the Project

This is my personal portfolio website, developed to showcase my background, technical skills, academic projects, and career interests as an IT undergraduate at the University of Moratuwa – Institute of Technology.

## Technologies Used

- React.js
- JavaScript
- HTML5
- CSS3
- Bootstrap 5
- React Router DOM

## Features

- Home page
- About Me section
- Technical Skills
- Projects showcase
- Contact information and contact form
- Downloadable CV
- Responsive design

## Getting Started

Clone this repository:

```bash
git clone https://github.com/Dismini56/Mihirandani-ePortfolio.git
```

Navigate to the frontend folder:

```bash
cd frontend
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm start
```

The application will run at:

`http://localhost:3000`
